# Himachal Pradesh Tourism — Traveling Website

A static website for a Himachal Pradesh travel agency, featuring tour packages,
popular destinations, founder/team info, traveller testimonials, an FAQ, and a
working contact form.

## Features

- **Responsive navigation** with hamburger menu (works on mobile)
- **Hero section** with call-to-action
- **Animated stats bar** (years, packages, travellers, destinations)
- **Tour packages & destinations** card grids
- **About section** with founder face name (Rajesh Sharma) and team avatars
- **Traveller testimonials**
- **FAQ accordion** (native `<details>` elements)
- **Contact form** with client-side validation and success message
- **Back-to-top button** and scroll-reveal animations
- **Active nav link highlighting** while scrolling

## Files

| File | Purpose |
|------|---------|
| `index.html` | Home page (hero, stats, packages, destinations, about, reviews, FAQ, contact) |
| `packages.html` | Tour packages page |
| `destinations.html` | Popular destinations page |
| `about.html` | About us, founder & team page |
| `contact.html` | Contact form & details page |
| `travil.css` | Base styles |
| `enhancements.css` | Stats, testimonials, FAQ, back-to-top styles |
| `script.js` | Menu, form validation, counters, scroll effects |
| `images/` | Package, destination and team images |

## Run locally

Open `index.html` in a browser, or use VS Code **Live Server**.
