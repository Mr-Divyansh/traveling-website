# Himachal Pradesh Tourism — Traveling Website

A static website for a Himachal Pradesh travel agency, featuring tour packages,
popular destinations, founder/team info, traveller testimonials, an FAQ, a
working contact form, a photo gallery with lightbox, and a D Web Studio page.

## Features

- **Responsive navigation** with hamburger menu (works on mobile)
- **Hero section** with call-to-action and remote background image
- **Animated stats bar** (years, packages, travellers, destinations)
- **Tour packages & destinations** card grids with remote (Unsplash) images
- **Photo gallery** with hover captions and click-to-open lightbox
- **About section** with founder face name (Rajesh Sharma) and team avatars
- **D Web Studio page** — services, portfolio gallery, animated stats, CTA
- **Traveller testimonials**
- **FAQ accordion** (native `<details>` elements)
- **Contact form** with client-side validation and success message
- **Back-to-top button** and scroll-reveal animations
- **Active nav link highlighting** while scrolling

## Files

| File | Purpose |
|------|---------|
| `index.html` | Home page (hero, stats, packages, destinations, gallery, about, reviews, FAQ, contact) |
| `packages.html` | Tour packages page |
| `destinations.html` | Popular destinations page |
| `about.html` | About us, founder & team page |
| `dwebstudio.html` | D Web Studio — services, work showcase, stats, CTA |
| `contact.html` | Contact form & details page |
| `travil.css` | Base styles |
| `enhancements.css` | Stats, gallery/lightbox, studio, page-hero styles |
| `script.js` | Menu, form validation, counters, scroll effects, lightbox |
| `images/` | Team and misc images (card/hero images load from Unsplash URLs) |

## Run locally

Open `index.html` in a browser, or use VS Code **Live Server**.
An internet connection is needed for remote images (Unsplash) and Font Awesome.
